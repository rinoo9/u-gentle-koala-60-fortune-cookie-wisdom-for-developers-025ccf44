# Fortune Cookie Wisdom for Developers

An entry for the [Fortune Cookie Wisdom for Developers](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44) bounty on make.fun: one original fortune-cookie line for a software developer, at most 120 characters.

## The entry

> Every TODO you leave is a letter to a stranger who is you, later.

Every developer leaves TODOs in the code, and every developer has returned months later to a TODO they no longer understand — written by a past self who feels like a stranger. The line turns that everyday truth around: the stranger you are writing to is you.

## How to run

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt`. The program is deterministic — no network, no randomness, no clock — so repeated runs produce byte-identical output.
